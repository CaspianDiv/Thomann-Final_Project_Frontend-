# 🎸 Thomann Clone

> Avropanın ən böyük musiqi alətləri mağazasının React əsaslı klonu  
> A React-based clone of Thomann — Europe's largest musical instrument store

🔗 **Live Demo:** [https://thomman-db.onrender.com](https://thomman-db.onrender.com)

---

## 🇦🇿 Azərbaycanca

### Haqqında

Bu layihə Avropanın ən böyük musiqi alətləri e-commerce platforması olan **Thomann**-ın React ilə hazırlanmış klon versiyasıdır. Layihə 2025-ci ildə diplom işi kimi təqdim edilmişdir.

### ✨ Əsas Funksionallıqlar

- 🔍 **Məhsul Axtarışı** — adına görə axtarış imkanı
- 🎛️ **Filtrasiya** — kateqoriya və parametrlərə görə filter
- 🛒 **Səbət (Cart)** — məhsul əlavə etmə, silmə, miqdar dəyişmə
- ❤️ **Wish List** — sevilən məhsulları saxlama
- 📝 **Qeydiyyat (Register)** — yeni istifadəçi yaratma
- 🔐 **Giriş / Çıxış (Sign In / Sign Out)** — istifadəçi autentifikasiyası

### 🛠️ İstifadə Edilən Texnologiyalar

| Texnologiya | Təyinat |
|-------------|---------|
| React | Frontend UI |
| React Router | Səhifə naviqasiyası |
| Axios | HTTP sorğuları |
| JSON Server | Mock backend / REST API |
| Node.js | Server mühiti |
| CSS / Styled Components | Dizayn |

### 🚀 Lokal İşə Salma

```bash
# Reponu klonla
git clone https://github.com/istifadeciadın/thomann-clone.git

# Qovluğa keç
cd thomann-clone

# Asılılıqları quraşdır
npm install

# JSON Server-i işə sal (ayrı terminalda)
npx json-server --watch db.json --port 3001

# Tətbiqi işə sal
npm start
```

Tətbiq `http://localhost:3000` ünvanında açılacaq.

## 🇬🇧 English

### About

This project is a React-based clone of **Thomann**, Europe's largest musical instrument e-commerce platform. The project was presented as a diploma thesis in 2025.

### ✨ Features

- 🔍 **Product Search** — search by product name
- 🎛️ **Filtering** — filter by category and parameters
- 🛒 **Shopping Cart** — add, remove, and update product quantities
- ❤️ **Wish List** — save favorite products
- 📝 **Register** — create a new user account
- 🔐 **Sign In / Sign Out** — full user authentication flow

### 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| React | Frontend UI |
| React Router | Page navigation |
| Axios | HTTP requests |
| JSON Server | Mock backend / REST API |
| Node.js | Server environment |
| CSS / Styled Components | Styling |

### 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/yourusername/thomann-clone.git

# Navigate to the project folder
cd thomann-clone

# Install dependencies
npm install

# Start JSON Server (in a separate terminal)
npx json-server --watch db.json --port 3001

# Start the application
npm start
```

The app will run at `http://localhost:3000`.
